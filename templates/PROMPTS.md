## 模板 1 · 通用动效（最常用）

```text
你是一位动效导演、运动设计师、工程师和声音设计师，要独立完成**一支 10 秒的动效短片**。

目标：这个风格最经典、同时最惊艳的形态——获奖候选 / 高端商业水准。
**一个干净、像模板的结果 = 失败。**
参照水准：Buck、ManvsMachine、Ordinary Folk、Giant Ant、Territory Studio、
Apple keynote motion、Pentagram motion identities、Behance/Motionographer 精选。

# 题材
{{主题：一句话说清要讲什么。例：一句话被拆开、又重新落定}}

# 输出规格（固定，不许改）
- 1920×1080，{{24 或 30}} fps，**精确 10.000 秒**（{{240 或 300}} 帧）
- H.264 MP4，立体声 AAC 48kHz
- 响度 −14 LUFS integrated，真峰值 ≤ −1 dBTP
- 文件名：video.mp4

# 技术路线
HTML + Canvas2D（或 SVG），一个纯函数 draw(t)，暴露 window.renderAt(t)，
用 headless 浏览器逐帧截图，ffmpeg 合成。
（你可以选更好的路线，但要说明为什么更好。）

# 创意种子
{{2–4 句：画面长什么样、故事怎么走。要具体到能画出第一帧。}}

# 必须命中的签名特征
{{3–6 条"观众闭眼能回忆起的画面单元"。不是形容词，是具体的画面。
例：
1. 暖白纸面，一条细墨地平线，几丛草
2. 一个红色圆点从画面上方砸进纸面，纸被压出凹痕
3. 字一个一个落下，落下时影子同时收紧
4. 第 9 秒，所有字被一个动作扫开，只剩影子
5. 结尾三个字落定，最后一个字是唯一的一抹朱红
}}

# 工作方式（按顺序，别跳）
1. **Treatment**：写下 0.5 秒内的 hook、怎么升级、60–75% 处的英雄时刻、
   结尾定格在哪一帧。把每个签名特征映射到一个具体时刻。
   保持一份 cue sheet（拍点与 hit 时间），画面和声音都读它。
2. **先做关键帧**：在 6–10 个关键时间点渲染静帧，**真的去看**。
   每一帧都要能当海报：构图、层次、留白、字体排布（字距/行高/字重/中文标点/5% 安全边距）。
   改到没有一处看起来是默认的、模板的、挤的、AI 味的。
3. **运动**：低分辨率预览，**逐帧看最快的动作**——间距、缓动、弧线、重叠、
   预备与跟随、运动模糊。不能有无意义的空档。
4. **声音**：写符合类型的音乐和音效，锁在 cue sheet 上。
   检查视觉 hit 是否落在音频 onset 上。按规格做母带。
5. **终检**：时长精确 / 分辨率 / 帧率 / 音频存在且响度对 / 无黑帧 /
   无 fallback 字体或豆腐块 / 边缘没裁掉元素 / 细线不闪 / 无 gradient banding。
6. **诚实自评**：最强的是什么，最弱的是什么，多给时间你会做什么。

# 规则（硬性）
- **渲染必须确定性**：每一帧都是时间 t 的纯函数。只用带种子的随机；
  物理和粒子预计算或闭式求解；不用实时时钟；不用状态触发的过渡。
- **同一个 t 画两次必须逐像素一致。**
- 素材只用 CC0 / 公有领域 / OFL / Apache / 可商用免费。每个来源和许可记进 CREDITS.md。
- 不用真实品牌商标，品牌名自己编。
- 屏幕上的文字必须正确自然：通顺中文、正确中文标点、无错字。

# 评委看什么
- **风格真实性**：专家能否一秒说出这是什么风格；每个签名技法是否到位且正确。
- **运动工艺**：有目的的缓动（除非机械否则不用 linear）、重叠与错峰、
  预备与跟随、弧线、允许时的挤压拉伸、物理一致、恰当的运动模糊；
  **转场由元素带动，不是 crossfade**。
- **节奏**：hit 锁在音乐上；忙与静有对比；不单调。
- **设计**：构图、网格、排版层次、克制的色板；质感只在风格需要处出现；没有一处看起来是意外的。
- **技术**：不抖（除非故意）、不跳、无锯齿、无 banding、无 fallback 字体。
- **声音**：符合类型、有音乐性、同步、做过母带。

# 交付前自评（1–10 分）
风格真实性 / 概念惊艳度 / 运动工艺 / 设计与排版 / 完成度与质感 / 声音与同步 / 技术执行
（6 = 模板级，8 = 高端公司，9 = 获奖候选）
**瞄准 9。先修最低分那一项。**

# 交付
video.mp4 + 一份报告：
1. 概念，两句话
2. 带时间码的 beat sheet
3. 每个签名特征是怎么实现的（具体到参数）
4. 技术路线
5. 检查数字（时长/分辨率/帧率/响度/真峰值）
6. **诚实说出三个最弱的地方**
```

## 模板 2 · 竖屏短视频（9:16）

把模板 1 的 `# 输出规格` 换成：

```text
- 1080×1920，30 fps，精确 10.000 秒（300 帧）
```

并追加：

```text
# 竖屏额外要求
- 前 3 秒必须抓住人（竖屏的流失率最高）
- 主体居中偏上（下 1/4 会被 UI 遮挡）
- 字号比横屏大 1.4–1.6 倍
- 字幕/花字不要贴边，留 8% 安全边距
- 节奏可以比横屏快一档（镜头中位 0.6 秒）
```

## 模板 3 · 只做关键帧（先看构图）

```text
你是一位版式设计师。为下面这段动效设计 **8 张关键静帧**，不要做动画。

题材：{{一句话}}

对每一帧，给出：
- 时间点（秒）
- 画面上有什么（位置、大小、颜色，具体到能画出来）
- 这一帧的"一句话作用"（它是 hook / 升级 / 英雄时刻 / 收尾）

硬要求：
- **每一帧单独截出来都要能当海报**
- 构图、层次、留白、字体排布都要成立（字距/行高/字重对比/中文标点/5% 安全边距）
- 强调色只有一处
- 说清楚这 8 帧连起来是一个什么结构（情绪弧线 / 五幕 / 拆解 / 一镜到底…）

输出后，自己指出哪一帧最弱、为什么。
```

**用法**：先跑这个，满意了再跑模板 1。**构图不对，动画白做。**

## 模板 4 · 只审片（给已有成片挑错）

```text
你是一位苛刻的动效评委。下面是一支动效的完整规格描述（或代码）。
请按这 7 个维度打 1–10 分，并**每条都给具体证据**：

1. 风格真实性（专家能否一秒说出风格；签名技法是否到位）
2. 概念惊艳度（有没有一个"没想到"的点）
3. 运动工艺（缓动是否有目的；有无预备/跟随/弧线；转场是否由元素带动）
4. 设计与排版（构图、层次、留白、字距、安全边距）
5. 完成度与质感（颗粒、边缘、细节；有没有"太干净"或"太脏"）
6. 声音与同步（hit 是否落在 onset 上；响度）
7. 技术执行（抖动、闪烁、banding、fallback 字体、裁切）

评分标准：6 = 模板级，8 = 高端公司，9 = 获奖候选。

然后：
- 指出**最该先修的 3 件事**（按性价比排序，不要按严重程度）
- 对每一件，给出**具体的改法和参数**
- 最后说：如果只能改一处，改哪一处

不要客套。不要"整体不错但是"。直接说问题。
```

## 模板 5 · 反向工程（从一张参考图复现）

```text
你是一位视觉分析师。下面这张图（或这段描述）是参考。

请做三件事：

## 1. 拆解它"只许有什么"
不是"它有什么"，是"它只许有什么、只许在哪里用什么"。
逐项写：
- 颜色：每个颜色的 hex + **面积占比**（例：七成暗部 / 两成中间调 / 一处强调）
- 光：几个主光？光从哪来？受光区域至少占多大？
- 材质/笔触：尺度用比例表示（例："笔触约画面宽的 1/100"）
- 线条：有没有描边？线宽？硬边还是软边？
- 质感：纹理幅度（例："画布纹 ±3%"）
- 一个"亮口"在哪

## 2. 写"定死的画法"（3–5 句，全是排除法）
例：
- 不描边；冷青做底，红粉招牌和尽头的橙光做主光
- 越远越被雾吃掉
- 倒影竖着拉长、被雨打出波纹
- 最近的几家拉着卷帘门，把前景压暗

## 3. 写"避免什么"
列出会一眼毁掉这个风格的 5 件事。
（参考：这类清单里 90% 是"太干净"——平滑渐变、套色完全对齐、平光、矢量硬边）
```

**用法**：拿到这三段之后，再套模板 1 做动画。**不要直接描述"我要一个赛博朋克风格"。**

> 这个写法的原型是 R 系列的「定死的画法」，原文见 [R1 节选](../sources/节选/R1-定死的画法.md)——三句话全是排除法，没有一个形容词。
