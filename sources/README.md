# 引用原文（节选）

> **这里为什么有文件？**
>
> 本 playbook 的每条结论都是从 341 份动效提示词里提炼的。大部分结论不需要看原文就能懂
> （"抽帧只抽被画的"这句话本身就够清楚）。但有 17 处，**不看原文你没法判断我说得对不对**——
> 要么是我把一句话总结成了规则，要么是我在反驳一个常见误解。
>
> 这 17 份就是那些"必须有原文才站得住"的地方。**每份只保留支撑结论的那几段，不是全文。**

**完整 341 份在**：[XiaoyeCodes/code-animation-prompts](https://github.com/XiaoyeCodes/code-animation-prompts)
（本仓库不复制全量，因为那是别人的仓库，去那里取才是正路。）

## 没有收录的（以及为什么）

| 没收录 | 为什么 |
|---|---|
| 其余 324 份提示词 | 它们的结论已被上面 17 份覆盖，或者结论本身不需要原文（如"手绘感""剪纸层叠"这类一眼就懂的） |

| `_统计.json` / `风格挑选.html` | 那是原仓库的检索工具，本 playbook 不用 |

## 关于改动

每份节选都在文件头写了：
- 来源文件路径
- 原文标题
- **为什么收录**（这条最重要，它说明我引用它是为了证明什么）
- 许可指向

**节选未改动原意**，只是删掉了与结论无关的章节。若发现断章取义，请开 issue。
